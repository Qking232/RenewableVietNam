Where your work lives

The shared shelf is stored in a Postgres database (Supabase). Submissions publish immediately — nothing is held back for review. If something unwanted appears, delete the row (or set its status to rejected) in the Supabase table editor: a web UI, no commands.

While the shared store is switched off, topics you add and the notes you write live only in this browser (local storage). Export saves them to a JSON file and Import restores them on another device.

Reference sources used

  • Ministry of Industry and Trade (MOIT) & the National Power Development Plan (PDP8)
  • EVN / EVNNPT — national utility and grid operator disclosures
  • IEA, IRENA, World Bank, ADB, UNDP, ILO — energy, finance and just-transition analysis
  • Global Energy Monitor, Ember, Global Wind Energy Council — asset and generation trackers
