Mathematical Formulation: Calculating IRR IRR = 15.65%

1. Fundamental Equation: The Internal Rate of Return (IRR) is the unique discount rate r that forces the cumulative Net Present Value (NPV) of all capital cash outflows and operating inflows to equal exactly zero:

NPV = Σ [ CF_t / (1 + r)^t ] = 0
Expanded for 7-Year Greenfield Lifecycle:
-$14.50M + [$3.03M/(1+r)¹] + [$4.04M/(1+r)²] + [$4.18M/(1+r)³] + [$4.27M/(1+r)⁴] + [$4.36M/(1+r)⁵] + [$4.44M/(1+r)⁶] + [$4.44M/(1+r)⁷] = $0

2. Numerical Solution via Trial Interpolation: Because r cannot be isolated algebraically from a 7th-degree polynomial, it is solved via numerical iteration or linear interpolation between two trial discount rates:

• Trial 1 (r₁ = 10.0% WACC): NPV₁ = +$1,845,200 USD (> 0)
• Trial 2 (r₂ = 18.0% Hurdle): NPV₂ = -$1,054,000 USD (< 0)
Linear Interpolation Formula:
IRR ≈ r₁ + [ NPV₁ / (NPV₁ - NPV₂) ] × (r₂ - r₁)
IRR ≈ 10.0% + [ 1.845M / (1.845M - (-1.054M)) ] × 8.0%
IRR ≈ 10.0% + [ 1.845M / 2.899M ] × 8.0% = 10.0% + 5.09% ≈ 15.09%
Exact Root via Newton-Raphson: IRR = 15.65%
