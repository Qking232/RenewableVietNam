How the search, the models and the decisions work
Search — the reference app's ladder (Repository.resolveCoinId): local list first, then CoinGecko /search.
Models — the app's 10 (QuantKt.MODEL_NAMES) + 6 added, each scoring −2…+2 (computeDay). Verdict thresholds are normalised to the score range.
Final decision — the day's verdict, graded against the next day's close: a BUY is correct if price rises, a SELL is correct if it falls, HOLD is neutral (gradeVerdict). Streaks count consecutive same-direction decisions (decisionStreak) and consecutive correct/incorrect days (gradedRun / correctStreak).
Portfolio — private to you. It is keyed to a code you choose: the page hashes it and Supabase's row-level security only ever returns rows for that hash, so nobody else can read your list, and the same code on another device gives the same portfolio. With no code it stays local to this browser. Each row shows the coin's live price, today's decision, its score and the current correct/incorrect run; export/import as JSON.
Backtest — replays the daily verdicts over up to ~1,000 days of Binance daily klines: a BUY invests fully at that day's close, a SELL moves to cash, HOLD keeps the current allocation. Compares against buy & hold with round-trip trades, win rate, max drawdown and exposure. The chart shows dates and dollar values — hover it for the exact date and both equity curves. Past performance does not predict future results.
Matrix backtest — the same strategy across the major coins (plus your portfolio coins) and every window, as a color-coded grid. Hover a cell for hold & difference; click one to open that coin at that window.
Trend lines & breakouts — swing highs and lows (pivot lookback 5/10/20) are connected into support and resistance lines on a date + price chart. A close beyond a line is a breakout (▲ above resistance, ▼ below support), dashed lines extend to the break, and every break is listed with price, line value and distance.
Demo trading — a paper wallet (virtual 10,000 USDT) per coin, stored in this browser and keyed to your private code like the portfolio. Buy and sell at the live Binance price, or press Trade the signal to execute what today's verdict implies. Nothing real is at stake.
Coin list: Binance spot pairs (cached 24h). Price/klines: Binance. Rev 0.11.
Data: Binance public API · CoinGecko. Model scores are a study aid, not financial advice.
